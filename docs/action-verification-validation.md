# 独立人脸动作校验交付记录

## 功能与接口（2026-09-17）

- Agent、Web SDK 和 Vue 组件统一使用 `verificationAction`，移除 `blinkVerification`，不提供旧参数兼容路径。
- 支持 `none`、`blink`、`mouth-open`、`turn-left`、`turn-right`；默认 `none`。每轮只执行一种动作。
- Vue 调用方在开始前随机选定动作并传入；本轮固定。组件重拍沿用动作，重置检测进度；重新随机选择需结束当前轮并重新打开。
- 张嘴验证闭嘴、张嘴、闭嘴；转头验证正脸、指定方向、回正。左右按使用者本人定义。新动作各阶段需连续 200ms，完成后再按配置的稳定时长抓拍。
- 张嘴和转头不要求眨眼，转头也不要求张嘴或闭嘴。无脸、多人、无效测量、明显移动或帧间隔超过 350ms 会重置动作进度；整轮 15 秒超时返回 `ACTION_TIMEOUT`。
- SDK 核对所请求动作的回显，缺少确认或返回另一动作时拒绝绑定该轮并报告 `ACTION_UNSUPPORTED`。被服务端拒绝的配置不会改变重拍继承的已确认动作。
- 复用随程序交付的 YuNet 与 Face Mesh。张嘴用唇间距/嘴宽；转头用鼻尖相对双眼轴的归一化偏移，不是角度估计。
